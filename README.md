# 📊 Proyecto RetailPro - Data Analytics

## 📝 Descripción del Proyecto
RetailPro es un proyecto integral de análisis de datos enfocado en evaluar el rendimiento de ventas, rentabilidad por producto y comportamiento de los clientes. El objetivo es brindar información clara y accionable para la toma de decisiones del equipo comercial.

## 🛠️ Herramientas Utilizadas
* **Base de Datos:** SQL Server (T-SQL)
* **Entorno de Desarrollo:** SQL Server Management Studio (SSMS) y Visual Studio Code
* **Visualización de Datos:** Power BI y DAX
* **Control de Versiones:** Git y GitHub

## 📂 Estructura del Repositorio
* `/scripts/`: Contiene los archivos con el código SQL (ej. `m5_consultas_joins.sql` para la vista principal).
* `/dashboards/`: Contiene los archivos `.pbix` con el modelado de datos y los reportes visuales.
* `/data/`: Archivos base y diccionarios de datos.

## 🚀 Cómo ejecutar este proyecto
1. Clonar este repositorio en tu computadora local.
2. Abrir SQL Server Management Studio (SSMS).
3. Abrir y ejecutar el script principal ubicado en `/scripts/m5_consultas_joins.sql` para generar las vistas consolidadas.
4. Abrir el archivo de Power BI para interactuar con el dashboard final.
